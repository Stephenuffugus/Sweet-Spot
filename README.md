# Sweet-Spot

Two games by Stephen / Lucid Winds live in this repo.

| Game | Path | What it is |
|---|---|---|
| **Sweet Spot** | [`sweet-spot.html`](sweet-spot.html) (repo root, `/`) | One-thumb tennis timing game. Tap when the cursor crosses the sweet zone. Shipped and live. |
| **Shardfall** | [`shardfall/`](shardfall/) | Side-view action roguelite RPG — destructible world, gem sockets, permadeath with persistent shards. In development. |

Both are single-file vanilla HTML/CSS/JS PWAs with no build step. Each folder documents itself;
start with `shardfall/README.md` for the roguelite.

Live: https://stephenuffugus.github.io/Sweet-Spot/ (Sweet Spot) ·
https://stephenuffugus.github.io/Sweet-Spot/shardfall/ (Shardfall)
